# 🐣 জুনিয়র ও ফ্রেশারদের জন্য সিনারিও-ভিত্তিক ইন্টারভিউ প্রবলেম ও উত্তর
### (Scenario-Based Problems for Junior Laravel Developers & Freshers)
**টার্গেট:** Junior Laravel Developer / Fresher (০–১.৫ বছর অভিজ্ঞতা)  
**উদ্দেশ্য:** কোনো জটিল ডিস্ট্রিবিউটেড সিস্টেম নয়, বরং প্রজেক্টের বাস্তব সমস্যাগুলো সে লারাভেলের বেসিক ফিচার (CRUD, Middleware, Validation, Relationships) দিয়ে সমাধান করতে পারে কিনা তা যাচাই করা।

## 📌 সিনারিও ১: "ই-কমার্স অর্ডার ও প্রোডাক্টের ডাটাবেজ ডিজাইন"
> **বাস্তব দৃশ্যপট:** আমাদের একটি অনলাইন শপ বানাতে হবে। সেখানে একজন কাস্টমার যেকোনো সময় অর্ডার করতে পারে, এবং একটি অর্ডারে ৩-৪ রকমের প্রোডাক্ট থাকতে পারে (যেমন: শার্ট, প্যান্ট, জুতো)। এর জন্য ডাটাবেজে কী কী টেবিল বানাবেন এবং তাদের মধ্যে রিলেশন কী হবে?

### 🎯 জুনিয়রের কাছ থেকে যা আশা করবেন:
সে কি বুঝতে পারছে যে Order এবং Product-এর মধ্যে সম্পর্ক **Many-to-Many** এবং এর জন্য মাঝে একটি পিভট (Pivot) টেবিল লাগে?

### 💡 আদর্শ উত্তর (Ideal Answer):
* **টেবিলসমূহ:**
  1. `users` (id, name, email, phone)
  2. `products` (id, name, price, stock)
  3. `orders` (id, user_id, total_amount, status)
  4. `order_items` (id, order_id, product_id, quantity, unit_price) ⬅️ *পিভট টেবিল*
* **লারাভেল Eloquent রিলেশন:**
  - `User hasMany Orders`
  - `Order belongsTo User`
  - `Order hasMany OrderItems`
  - `Order belongsToMany Products` (using `order_items` table)
* 🚩 **রেড ফ্ল্যাগ:** যদি বলে "অর্ডার টেবিলেই প্রোডাক্টের নাম কমা দিয়ে লিখে রাখব" (যেমন: `shirt, pant`)—তাহলে তার রিলেশনাল ডাটাবেজ সম্পর্কে কোনো ধারণাই নেই।

## 📌 সিনারিও ২: "অ্যাডমিন প্যানেলে সাধারণ ইউজারের প্রবেশ ঠেকানো"
> **বাস্তব দৃশ্যপট:** আমাদের ওয়েবসাইটে সাধারণ কাস্টমার ও অ্যাডমিন উভয়ই লগইন করতে পারে। কিন্তু কোনো সাধারণ কাস্টমার যদি ব্রাউজারের অ্যাড্রেসবারে সরাসরি `http://mysite.com/admin/dashboard` লিখে এন্টার দেয়, তাকে কীভাবে আটকাবেন?

### 🎯 জুনিয়রের কাছ থেকে যা আশা করবেন:
সে কি লারাভেলের **Middleware** ব্যবহার করতে জানে, নাকি কন্ট্রোলারের প্রতিটা মেথডে গিয়ে `if-else` লেখার চিন্তা করে?

### 💡 আদর্শ উত্তর (Ideal Answer):
* **সমাধান:** একটি কাস্টম মিডলওয়্যার (যেমন: `AdminMiddleware`) তৈরি করা।
```bash
php artisan make:middleware AdminMiddleware
```
* **মিডলওয়্যার কোড:**
```php
public function handle(Request $request, Closure $next)
{
    // চেক করা ইউজার লগইন আছে কিনা এবং তার রোল অ্যাডমিন কিনা
    if (auth()->check() && auth()->user()->role === 'admin') {
        return $next($request);
    }

    // অ্যাডমিন না হলে ড্যাশবোর্ডে বা হোমপেজে ফিরিয়ে দেওয়া
    return redirect('/')->with('error', 'আপনার এই পেজে প্রবেশের অনুমতি নেই!');
}
```
* **রাউটে অ্যাপ্লাই করা:**
```php
Route::middleware(['auth', 'admin'])->prefix('admin')->group(function () {
    Route::get('/dashboard', [AdminController::class, 'index']);
});
```
* 🚩 **রেড ফ্ল্যাগ:** বলে "ব্লেড ফাইলে হাইড করে রাখব"—সে বোঝে না যে URL টাইপ করলে ব্লেডের হাইড কোনো কাজে আসে না।

## 📌 সিনারিও ৩: "প্রোফাইল ছবি আপলোড ও পুরনো ছবি ডিলিট করা"
> **বাস্তব দৃশ্যপট:** একজন ইউজার প্রোফাইল পিকচার পরিবর্তন করল। ইউজার যাতে ১ জিবির কোনো ফাইল বা ভাইরাস না দেয় এবং নতুন ছবি সেভ হওয়ার পর সার্ভারে জমা থাকা পুরনো আগের ছবিটি যেন ডিলিট হয়ে সার্ভারের মেমোরি ফাঁকা হয়—এটি কীভাবে করবেন?

### 🎯 জুনিয়রের কাছ থেকে যা আশা করবেন:
ফাইল ভ্যালিডেশন (`mimes`, `max`) এবং `Storage::delete()` ব্যবহারের নিয়ম জানা।

### 💡 আদর্শ উত্তর (Ideal Answer):
```php
public function updateProfilePicture(Request $request)
{
    // ১. ফাইল ভ্যালিডেশন (শুধু ছবি ও সর্বোচ্চ ২ এমবি)
    $request->validate([
        'avatar' => 'required|image|mimes:jpeg,png,jpg,webp|max:2048',
    ]);

    $user = auth()->user();

    // ২. আগের পুরনো ছবি থাকলে স্টোরেজ থেকে ডিলিট করা
    if ($user->avatar && Storage::disk('public')->exists($user->avatar)) {
        Storage::disk('public')->delete($user->avatar);
    }

    // ৩. নতুন ছবি আপলোড করে ডাটাবেজে পাথ সেভ করা
    $path = $request->file('avatar')->store('avatars', 'public');
    $user->update(['avatar' => $path]);

    return back()->with('success', 'প্রোফাইল ছবি সফলভাবে আপডেট হয়েছে!');
}
```
* 🚩 **রেড ফ্ল্যাগ:** ফাইল ভ্যালিডেশন ছাড়াই সরাসরি `move()` করা অথবা পুরনো ছবি ডিলিট না করে সার্ভারে গারবেজ ফাইল জমতে দেওয়া।

## 📌 সিনারিও ৪: "অর্ডার করার পর ইনভেন্টরি স্টক হ্রাস ও আউট-অব-স্টক হ্যান্ডলিং"
> **বাস্তব দৃশ্যপট:** একটি শার্টের স্টক আছে ৫টি। একজন কাস্টমার ৩টি অর্ডার করল। কীভাবে স্টক কমাবেন এবং যদি কেউ ৭টি কিনতে চায় বা স্টক শূন্য হয়ে যায়, তবে কীভাবে আটকাবেন?

### 🎯 জুনিয়রের কাছ থেকে যা আশা করবেন:
লজিক্যাল কন্ডিশন এবং ডাটাবেজ আপডেট মেথড (`decrement`) সম্পর্কে জানা।

### 💡 আদর্শ উত্তর (Ideal Answer):
```php
public function placeOrder(Request $request, $productId)
{
    $quantity = $request->input('quantity');
    $product = Product::findOrFail($productId);

    // ১. পর্যাপ্ত স্টক আছে কিনা যাচাই
    if ($product->stock < $quantity) {
        return back()->with('error', "দুঃখিত! মাত্র {$product->stock} টি প্রোডাক্ট স্টকে আছে।");
    }

    // ২. অর্ডার তৈরি করা
    Order::create([
        'user_id' => auth()->id(),
        'product_id' => $product->id,
        'quantity' => $quantity,
    ]);

    // ৩. স্টক থেকে অর্ডার করা পরিমাণ বিয়োগ করা
    $product->decrement('stock', $quantity);

    return redirect('/orders')->with('success', 'অর্ডার সফলভাবে সম্পন্ন হয়েছে!');
}
```
* 🚩 **রেড ফ্ল্যাগ:** স্টক মাইনাস হয়ে নেগেটিভ (যেমন: `-2`) হয়ে যাওয়ার ঝুঁকি চেক না করা।

## 📌 সিনারিও ৫: "সার্চ ও ড্রপডাউন ক্যাটাগরি ফিল্টারিং"
> **বাস্তব দৃশ্যপট:** আমাদের প্রোডাক্ট পেজে একটি সার্চ বক্স আছে (নাম লিখে খোঁজা) এবং একটি ড্রপডাউন আছে (ক্যাটাগরি সিলেক্ট করা)। কাস্টমার নাম লিখে সার্চ করতে পারে, আবার ক্যাটাগরি দিয়েও ফিল্টার করতে পারে। কন্ট্রোলারে এই কুয়েরিটি কীভাবে লিখবেন?

### 🎯 জুনিয়রের কাছ থেকে যা আশা করবেন:
সব ডেটা একসাথে না এনে কীভাবে লারাভেলের `when()` মেথড বা কন্ডিশনাল কুয়েরি দিয়ে ফিল্টার করা যায়।

### 💡 আদর্শ উত্তর (Ideal Answer):
```php
public function index(Request $request)
{
    $query = Product::query();

    // যদি সার্চ বক্সে কিছু লিখে থাকে
    if ($request->filled('search')) {
        $query->where('name', 'like', '%' . $request->search . '%');
    }

    // যদি ড্রপডাউনে ক্যাটাগরি সিলেক্ট করা থাকে
    if ($request->filled('category_id')) {
        $query->where('category_id', $request->category_id);
    }

    // পেজিনেশন সহ রেজাল্ট নিয়ে আসা
    $products = $query->latest()->paginate(12);

    return view('products.index', compact('products'));
}
```
*(বোনাস পয়েন্ট পাবে যদি প্রার্থী লারাভেলের `$query->when(...)` মেথড উল্লেখ করতে পারে)*
